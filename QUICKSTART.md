# MyFLOW — быстрый старт

Локальная диктовка для Windows: говоришь — текст появляется там, где стоит курсор.
Всё работает на твоём компьютере: голос никуда не отправляется.

Подробное руководство со схемами, замерами и настройками — в [README.md](README.md).

## Что нужно

* Windows 10 или 11 (64-бит)
* Python 3.13 — [python.org](https://www.python.org/downloads/) (при установке
  поставь галочку «Add python.exe to PATH»). Батник создаёт окружение на 3.13;
  руками можно и на 3.11+
* Микрофон
* ~7 ГБ на диске: модели, бинарники серверов и LLM
* Видеокарта **не обязательна**: распознавание идёт на процессоре

## Шаги

Батники из папки MyFLOW запускаются двойным кликом; остальное — команды PowerShell или ручное копирование файлов (шаги 4–5).

| Шаг | Что запускать | Что будет |
|---|---|---|
| 1 | `install-myflow.bat` | проверит Python, создаст окружение `.venv`, поставит зависимости и запустит доктора |
| 2 | `.venv\Scripts\pip install soundfile "onnx-asr[hub]" kaldi_native_fbank` | GigaAM, проверка голоса, аудио фраз (без них работает не всё) |
| 3 | `fetch-models.bat` | скачает whisper (~547 МБ; докачка включена — можно запускать повторно). GigaAM (~214 МБ) докачается сам при первом распознавании |
| 4 | вручную: бинарники серверов | `llama-server.exe` → `bin\llama-cpp\`, `whisper-server.exe` → `bin\whisper\Release\` (ссылки в README) |
| 5 | вручную: модели | `Qwen3-4B-Instruct-2507-Q8_0.gguf` → `models\`, `model.onnx` → `models\voiceprint\`, `silero_v6.onnx` → `data\vad_models\` (ссылки и команды — в README) |
| 6 | доктор | `.venv\Scripts\python -X utf8 tools\doctor.py` — покажет, всё ли готово, и что делать, если нет |
| 7 | `start-myflow.bat` | запустит диктовку (панель управления в консоли) |
| 8 | говори | поставь курсор в нужное окно и нажми горячую клавишу |

### Шаг 2 подробнее: три пакета, без которых половина не работает

Базовый `requirements.txt` ставит только ядро. Эти три пакета в нём закомментированы,
поэтому доставь их отдельно — в то же окружение `.venv`:

```powershell
.venv\Scripts\pip install soundfile "onnx-asr[hub]" kaldi_native_fbank
```

| Пакет | Что даёт |
|---|---|
| `onnx-asr[hub]` | **GigaAM** — основной движок распознавания (57 мс). Без него приложение уходит в whisper |
| `kaldi_native_fbank` | **проверка голоса** — отсекает чужую речь |
| `soundfile` | аудио фраз; без него доктор не напишет «ВСЁ ГОТОВО ✓» |

### Шаг 5 подробнее: модели, которых нет в git

LLM-модель (`models\Qwen3-4B-Instruct-2507-Q8_0.gguf`, 4 ГБ), модель проверки
голоса (`models\voiceprint\model.onnx`) и **VAD-модель** (`data\vad_models\silero_v6.onnx`,
2.3 МБ) в git не лежат — ссылки на скачивание и готовые команды в
[README.md](README.md). Без VAD-модели приложение не стартует. Постпроцессор (`models\myflow-postproc-*.gguf`) — собственная
дообученная LoRA проекта, на HuggingFace её нет: бери у автора. Без него работает
базовая LLM — полировка чуть грубее, остальное как обычно.

## Как диктовать

* **Авто-режим** — говоришь, и когда пауза становится длинной, фраза распознаётся и
  вставляется сама.
* **PTT (push-to-talk)** — держишь клавишу, говоришь, отпускаешь: вставляется.
  Переключение режима — в панели, строка «Режим диктовки».

Текст вставляется туда, куда указывает строка **«Куда вставлять»**:

| Значение | Куда попадает текст |
|---|---|
| активное окно (Ctrl+V) | в то окно, где сейчас курсор — обычный режим |
| чат OpenCode (без фокуса) | прямо в консоль OpenCode, окно можно не трогать |
| DeepSeek Harness (без фокуса) | прямо в чат DeepSeek Harness (нужен мост, см. ниже) |
| никуда (только история) | никуда не вставляется, но каждая фраза пишется в историю |

## Мост в DeepSeek Harness (по желанию)

Чтобы диктовать прямо в чат DSH без переключения окон: выбери в панели «Куда
вставлять» → **DeepSeek Harness (без фокуса)**, появится строка **«Мост в DSH»** —
нажми Enter. MyFLOW сам найдёт установленный DeepSeek Harness, положит в него плагин
и попросит перезапустить приложение. Позже мост обновляется сам.

## Где что лежит

| Папка | Что там |
|---|---|
| `data\myflow.sqlite` | история диктовок (что услышали, что поправил, аудио последних фраз) |
| `data\settings.json` | настройки |
| `models\` | модели (в git не попадают) |
| `data\train\` | датасеты и результаты дообучения |
| `data\*.log` | журналы |

## Если что-то не работает

1. запусти `.venv\Scripts\python -X utf8 tools\doctor.py` — он перечислит, чего не хватает;
2. если ругается на порт — его заняла другая программа, посмотри в докторе;
3. если распознавание молчит — проверь строку «Микрофон» в панели и уровень сигнала;
4. журналы лежат в `data\*.log`.

## Для разработки (необязательно)

* постпроцессор обучается на твоих правках: `tools\retrain_postproc.py` (ставит новую
  модель **только если она не хуже** текущей);
* замер по звуку: `read-chapter.bat` (открывает текст и читает вслух) + разбор
  `tools\analyze_readaloud.py`;
* словарь имён и терминов: `tools\name_dictionary.py`;
* тесты: `.venv\Scripts\python -X utf8 -m unittest discover -s tests -t .`

Панель управления — консольный пульт (TUI): он быстрый и показывает всё. Скриншот,
разбор архитектуры и замеры — в [README.md](README.md).
