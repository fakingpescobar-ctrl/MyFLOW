# MyFLOW — локальный голосовой диктант (копия архитектуры Wispr Flow)

Полностью локальный диктант-ассистент по образцу Wispr Flow, но без облака:
**Whisper (ASR) + Gemma-4-12B (полировка) на RTX 3080**, всё в SQLite.

## Архитектура (зеркало Wispr Flow)

| Слой | Wispr Flow | MyFLOW | Статус |
|---|---|---|---|
| Запись | AudioWorklet 16k mono, чанк 640 (40мс) | `audio.py`: sounddevice 16k mono, чанк 640, Float32→Int16 (кламп как у них) | ✅ |
| Горячие клавиши | PTT Hold, Esc cancel, шорткаты | `main.py`: глобальный PTT (F8), cancel (F9) через pynput | ✅ |
| Режимы записи | — | `pick_mic.py` при старте (стрелки ↑/↓, Enter, Esc): микрофон → режим (`ptt` — по кнопке, `auto` — слушает постоянно) | ✅ |
| VAD авто-стоп | — | пауза >0.9с завершает фразу; авто-стоп PTT только при наличии речи (стартовая тишина не рубит) | ✅ |
| Инкрементальный ASR | streaming → live text | `on_interval`: слайдинг-окно (4с) каждые ~1.8с → драфт-превью «… текст» (не вставляется) | ✅ |
| ASR | gRPC streaming → Baseten «Canto 1.0» | `asr.py` → whisper-server (large-v3-turbo, CUDA) `:8081` | ✅ |
| Полировка | gpt-5-nano / gpt-oss-120b (филлеры, пункт., стили) | `polish.py` → llama-server (Qwen3-4B Q8) `:8082`; стили plain/terminal/casual/formal + правило чисел few-shot | ✅ |
| Instruct (пересказ, команды) | gpt-oss-120b | тот же Qwen3-4B, стиль `summarize` (0.3-0.5с, пересказ 2-3 пр.) | ✅ |
| Голосовые команды | — | `commands.py`: точные фразы/префиксы/LLM-интент (стоп, скип, перескажи, списком, отправь, удали последнее, новый абзац) | ✅ |
| Вставка | C# helper (accessibility) | `insertion.py`: Clipboard + SendInput Ctrl+V | ✅ |
| БД | flow.sqlite (History/Dictionary/Settings) | `db.py`: SQLite history/dictionary/settings_kv | ✅ |
| Словарь | personal dictionary, авто-обучение из правок | `learning.py`: diff правок → learned-слова (порог 2); **per-app**: словарь с маской окна (app_mask), обучение в контексте окна, `unknown` → глобальный | ✅ |
| Телеметрия | Sentry/PostHog (облако) | поведение НЕ телеметрируется (локально) | ✅ |

## Запуск

```
powershell -File scripts\start-asr.ps1      # whisper-server :8081 (видимое окно)
powershell -File scripts\start-llm.ps1      # llama-server :8082 (видимое окно)
.venv\Scripts\python -m myflow.main         # сам MyFLOW (PTT=F8)
```

Тест пайплайна без клиента: `.venv\Scripts\python test-e2e.py 4` (запись 4с → распознавание).

## Вводный план (фазы)

- [x] Ф0 среда: venv py3.13, whisper.cpp CUDA 12.4, model large-v3-turbo (547MB), llama-server + форматтер Qwen3-4B Q8 (4GB)
- [x] Ф1 запись + PTT + тишина-фильтр (громкость <0.01 → скип)
- [x] Ф2 ASR: whisper-server, RTF≈0.12 (4с аудио за 0.5с)
- [x] Ф3 полировка: Qwen3-4B, «8081» из «восемь тысяч восемьдесят один», филлеры/пунктуация
- [x] Ф4 вставка Ctrl+V (clipboard save/restore)
- [x] Ф5 БД + learn из правок (SequenceMatcher diff, порог 2)
- [x] Ф7 форматтер: gemma-4-12B (8.4с) → Qwen3-4B Q8 (0.6с, 14x); VRAM 10GB = ровно 1 LLM + whisper
- [x] Ф8 стили per-app: `style_by_app` (маска окна → стиль, дефолты терминалы) + hotkey F7 (цикл plain→casual→formal→terminal→summarize, debounce 0.3с, «авто» сбрасывает)
- [x] Ф6 оверлей статуса: прозрачное topmost-окно (правый низ, клик-сквозь, авто-скрытие 1.8с) — «● запись / ⚙ распознавание / ⚙ полировка / ✓ вставлено / ✗ ошибка»; flag `overlay`, потокобезопасно через Queue
- [x] Ф9 авто-обучение из правок: watcher 6с после вставки читает буфер, скопированная правка нашего текста (пересечение токенов ≥50%) → diff → dictionary; per-app: порог 2 в рамках одного окна, unknown-окно → глобально
- [x] Ф10 режимы ptt/auto: выбор при старте (TUI стрелками), «авто» слушает постоянно (триггер 3 чанка, pre-roll 0.25с, отсев кликов ≥180мс речи, фраза по паузе, F8=срочный стоп, F9=скип, лимит 60с) — очередь+worker, запись не теряет фразы во время распознавания
- [x] Ф11 live-превью (инкрементальный ASR): хвост записи каждые ~1.8с → драфт-whisper → «… текст» в консоль/оверлей; флаг `live_preview`; вставка всегда после полной транскрипции (честно: e2e-выигрыш только UX-ощущение)
- [x] Ф12 голосовые команды (commands.py): точные фразы (стоп/скип/удали последнее/новый абзац/отправь/перескажи/списком), префиксы с аргументом (перескажи X/списком X), LLM-интент на явных маркерах. «отправь X» с аргументом НЕ перехватывается (защита от ложных срабатываний). Стиль `list` для оформления маркированным списком.

## Ограничения / честно

- **Пак моделей (протестированы 4, 07.09.2026): единственный годный — Qwen3-4B-2507 Q8** (обе роли: поль 0.3-0.9с, пересказ 0.3-1.3с, числа верны с NUMBERS_RULE). Забракованы: Qwen3.5-9B UD/Coder и Nemotron-3-Nano-4B (thinking-режим: content пуст при пересказе, не отключается reasoning:off//no_think), gemma-3n-E4B (поль копирует, пересказ нестабилен/self-repeat). При этом Nemotron хорош для поль (0.5с, 8081 верно) — резерв.
- Числа словами → цифрами: 4B систематически путает «восемь тысяч восемьдесят один» в 8881 БЕЗ few-shot; правило в промптах (polish «Пример: ...», summarize «Числа словами...») чинит стабильно.
- 10GB VRAM = одновременно только 1 LLM + whisper (две LLM не влезают, оффлоад убивает скорость).
- Авто-обучение ловит правки только если они скопированы в буфер (выделение + Ctrl+C) в окне 6с после вставки; правки мышью без копирования не видны. Есть и явный CLI-вызов `learn_from_edit(text)`. Per-app порог 2 — внутри одного окна (правки в разных окнах не «складываются»).
- Голосовые команды: «отправь X» с аргументом намеренно НЕ перехватывается («отправь документы Тане» — текст, не команда); команды с аргументом (перескажи/списком) могут сработать, если ты реально диктуешь о пересказе списком — это компромисс за точность. «удали последнее» работает через Ctrl+Z не дольше 60с после вставки (иначе риск откатить чужое). Переоформление последней фразы без аргумента («перескажи», «списком») вставляет результат НИЖЕ оригинала (дубль — через замену выделения делать небезопасно).
- Live-превью не ускоряет финальную вставку (полная транскрипция при отпускании кнопки/паузе) — это живой отклик во время длинных диктовок.
- Вставка идёт через буфер обмена (может конфликтовать с чужой вставкой; restore-логика есть).
- pynput-global-hotkeys требуют прав; в редких сессиях UAC PTT не сработает.
